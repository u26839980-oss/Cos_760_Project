Project Goal

Compare transcripts from three off‑the‑shelf ASR engines (Whisper, Lelapa, wav2vec‑2.0) on Setswana speech, then measure how transcription differences affect topic coherence (LDA, BERTopic, NMF).

    Kagiso – Topic modelling & coherence

    Shaun – Data wrangling, evaluation framework, integration, report assembly

    Build ASR wrappers (Josh, in src/asr.py).

        For Whisper: a function that loads a model (e.g., large-v3), transcribes an audio file with language="tn", and returns the text.

        For wav2vec‑2.0: load a pre‑trained checkpoint such as facebook/wav2vec2-xls-r-300m (or a publicly available fine‑tuned variant like DSFSI’s multilingual Whisper). Wrap it in a similar transcribe function.

    Build a preprocessing script (Kagiso, in src/preprocess.py).
    Include a cleaning function that lowercases text, removes punctuation and digits, and optionally filters out a small initial list of Setswana stopwords (e.g., le, a, o, ba, e, ka, wa, mo, go, ke). The output should be a single space‑separated string of tokens.

    Test a full, thin pass (Shaun orchestrates).
    Take one test audio → transcribe with Whisper → clean the text → train a dummy LDA model with gensim and print a couple of topics. This confirms the pipeline connects end‑to‑end.

Once step 6 completes, you are pipeline‑ready.

Lead: Josh; Support: Shaun (computing resources, audio preparation).

        Save outputs in transcripts/wav2vec/.

    Run Lelapa transcription (Josh, with Shaun’s help for API access).

        Implement a simple HTTP POST request that sends the audio file and receives the transcript.

        Store results in transcripts/lelapa/.

Output: Three folders of plain‑text transcripts with identical file naming.
Phase 3: Topic Modelling (15–19 May)

Goal: Train LDA, BERTopic, and NMF on each transcript set, compute coherence scores, and generate visualisations.
Lead: Kagiso; Support: Josh with embeddings for BERTopic.

    Preprocess all transcripts (Kagiso).

        Run the cleaning function from Phase 1 on every transcript.

        For each ASR system, create a list of documents (one document per utterance or per short time segment).

        Save the cleaned document lists as JSON files.

    Create document‑term matrices (for LDA and NMF).

        Use scikit‑learn’s CountVectorizer (for LDA) and TfidfVectorizer (for NMF), with parameters like max_df=0.9 and min_df=2.

    Train LDA (using gensim).

        Convert the cleaned documents into a list of token lists, then create a gensim dictionary and a bag‑of‑words corpus.

        Train an LdaModel with 10 topics, 10 passes over the data.

        Compute two coherence measures: NPMI (c_npmi) and UMass (u_mass), using gensim’s CoherenceModel.

    Train BERTopic.

        Instantiate a BERTopic model with a multilingual sentence‑transformer embedding (e.g., “paraphrase-multilingual-MiniLM-L12-v2”) and language="multilingual".

        Fit the model on the list of cleaned documents; retrieve topic assignments and topic information.

        Use BERTopic’s built‑in topic_diversity method. Additionally, manually compute NPMI coherence by extracting top‑n words per topic and feeding them to gensim’s CoherenceModel (by constructing a topic‑list format).

    Train NMF.

        Fit an NMF model (10 components) on the TF‑IDF matrix.

        Extract the most important words per topic.

        Compute NPMI coherence by supplying these topic‑word lists to gensim’s CoherenceModel (this requires a small manual mapping).

    Record all coherence scores in a CSV (results/coherence_scores.csv) with columns: ASR_system, topic_model, NPMI, UMass, topic_diversity.

    Create visualisations.

        For LDA: use pyLDAvis to generate an interactive HTML plot.

        For BERTopic: generate topic visualisations (e.g., intertopic distance map, bar chart of top words per topic).

        Save all plots in results/.

Phase 4: Evaluation & Comparative Analysis (20–22 May)

Goal: Build comparative charts, conduct a native‑speaker review, and analyse the effect of normalisation.
Lead: Shaun; Support: Kagiso provides topic outputs.

    Comparative NPMI bar chart (Shaun).

        Use matplotlib or seaborn to create a grouped bar chart: x‑axis = topic model (LDA, BERTopic, NMF), colour‑grouped by ASR system (Whisper, Lelapa, wav2vec).

        Save as results/npmi_comparison.png.

    Qualitative native‑speaker assessment.

        If the team does not have a Setswana speaker, reach out to the DSFSI lab or the supervisor for a contact.

        From the best‑performing ASR + topic model combination (according to NPMI), extract the top 10 keywords per topic and 3–5 example sentences.

        Ask the evaluator to rate each topic’s interpretability on a 1–5 scale and to note any strange words or obvious transcription errors.

        Summarise findings in a table.

    Impact of text normalisation (Shaun/Kagiso).

        Choose one ASR output, run the pipeline both with and without the full cleaning/normalisation step (the stopword removal and lowercasing done in preprocessing).

        Compute and compare NPMI scores.

        Produce a before/after bar chart for inclusion in the report.

    Compile a summary document of all results for the report.
